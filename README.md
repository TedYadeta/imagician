# imagician
A Bash script I wrote to help me with downloading and validating Linux ISOs

# WARNING!

This script will download Linux ISOs and validate their SHA256 OR SHA512 CHECKSUMS only! I plan on adding additional GPG validation as well, but please be advised that this script is still experimental. I **strongly** recommend using this for homelab use only! I would not use this in Production!

Current distros available:

- Alpine Linux
- Arch Linux
- Debian
- OpenSUSE
- NixOS
- Ubuntu
